== Rich Text Sanitizer Foundation

`DroomClient::SafeHtmlSanitizer` provides a centralized allowlist sanitizer for rich-text fields.

Usage:

	sanitized = DroomClient::SafeHtmlSanitizer.sanitize(input_html)

Notes:

* Nil-safe input handling (`nil` returns empty string)
* Explicit allowlist tags and attributes
* Unsafe link protocols (for example `javascript:`) are stripped
* Foundation-only; consuming apps must opt in per rich-text field
